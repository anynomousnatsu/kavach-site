# Images the site is waiting for

Ten files. Drop each one into `assets/img/` **with the exact filename below** and it
appears automatically — no code change needed. Until a file exists, its slot shows a
hatched tile that names the file it is waiting for, so nothing breaks and nothing shifts.

**Order of impact if you only do a few:** `kit-cutout.png` → `work-kitchen.jpg` →
`feature-night.jpg` → `work-hotel.jpg` → `work-warehouse.jpg` → the rest.

---

## House style — paste this into every prompt

> Documentary commercial photography, real Kathmandu interior, shot on 35mm, f/2.8,
> natural and practical light only, cool neutral white balance, slightly desaturated,
> fine film grain, no HDR, no lens flare. Technicians wear matte charcoal-black work
> uniform with lime-green (#C5F24C) trim, black nitrile gloves, ID lanyard. Faces not
> visible or turned away from camera. No text, no logos, no watermarks. Candid working
> posture — not posed, not smiling at camera.

Keep the palette cool and neutral: stainless steel, grey tile, concrete, warm practical
bulbs. The site supplies the lime; the photos should not fight it.

## After you drop the files in

```bash
python -m http.server 8737
```

Open <http://localhost:8737> and confirm no hatched tiles remain. Then compress before
deploying — these should be well under 300 KB each for a Nepali mobile connection:

```bash
npx @squoosh/cli --mozjpeg '{"quality":78}' assets/img/*.jpg
```

If you would rather not generate photos at all, the original hand-drawn SVG
illustrations are still in `assets/img/` (`hero-kit.svg`, `svc-kitchen.svg`,
`svc-room.svg`, `svc-store.svg`, `svc-home.svg`). Point the `<img src>` at those
instead — the tiles will crop them to the same shapes.
